# Tennis Video Helper v0.1.3

这一版为官网和 Windows 桌面软件补齐中英文切换，并建立了面向后续开发与发布的项目级 Codex 指南。

## 主要更新

- 官网新增中文 / English 切换，覆盖导航、功能、架构、球场主题、安装、反馈和动态状态文字。
- 网页语言选择保存在浏览器本地，刷新或重新打开后自动恢复；桌面与约 390×844 手机布局均保持可读。
- 桌面软件在设置中新增语言选择，中文与英文可以即时切换，关闭重开后继续使用上次选择。
- 桌面菜单、工作台、参数面板、球场名称、更新对话框和主要状态提示均支持英文显示。
- 新增仓库根目录 `AGENTS.md`，统一代码分层、测试矩阵、数据安全、Windows 打包、官网和 Release 同步要求。

## 安装与升级

- 支持 Windows 10 / 11 x64。
- 安装包内置 Python 运行环境、ONNX 模型、FFmpeg 和 ffprobe，无需另外安装。
- 可以直接覆盖安装旧版本；升级会替换程序内部文件，但保留用户设置和外部输出目录。
- 当前安装包没有数字签名，Windows SmartScreen 可能显示未知发布者。请只从本 Release 下载并核对 SHA-256。
