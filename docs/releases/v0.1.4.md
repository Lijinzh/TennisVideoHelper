# Tennis Video Helper v0.1.4

这一版重点修复长批次复核流程：用户可以分多次导出候选，不会因为一次导出丢失尚未阅读、尚未选择或准备稍后处理的片段；同时在输入和输出路径旁加入直接打开文件夹的快捷按钮。

## 主要更新

- 导出勾选片段后，未导出、未读和暂未处理的候选继续保留在复核工作台，可返回继续筛选。
- 多次导出会累计发布结果和 `review-selection.json`，已导出的候选不会重复占用待处理列表。
- 输入路径旁新增“打开”按钮：输入为视频时打开其所在文件夹，输入为文件夹时直接打开该目录。
- 输出路径旁新增“打开”按钮；目录不存在时会先安全创建，再交给 Windows 文件资源管理器打开。
- 官网和完整文档同步到 v0.1.4，并更新精确安装包、大小和 SHA-256 信息。

## 安装与升级

- 支持 Windows 10 / 11 x64。
- 安装包内置 Python 运行环境、两个 ONNX 模型、FFmpeg、ffprobe 和 15 张球场背景，无需另外安装 Python 或 FFmpeg。
- 可以直接覆盖安装 v0.1.3；升级只替换程序内部文件，保留用户设置和外部输入、输出目录。
- 当前安装包没有数字签名，Windows SmartScreen 可能显示未知发布者。请只从本 Release 下载并核对 SHA-256。
