# Tennis Video Helper v0.1.2

这一版把像素球场从网站带进了桌面软件，并补齐了主题持久化、自动更新检查和官网发布信息。

## 主要更新

- 软件设置新增完整的球场背景切换，共包含 15 种像素球场主题。
- 包含陕北风黄土、法网红土、温网草地、美网夜场、澳网蓝场、上海旗忠、北京钻石、马德里魔力盒、里约、印第安维尔斯，以及多种概念球场。
- 球场背景即时生效，卡片采用半透明深色层，保证视频预览、参数和状态文字清晰可读。
- 主题选择通过 QSettings 保存，关闭并重新打开软件后仍会恢复。
- 官网球场画廊扩展到 15 个场景，并增加浅色、深色、跟随系统及球场配色选项。
- 更新检查调整为每日自动检查，也可从“帮助 → 检查更新”手动触发。
- 官网新增 GitHub Star 引导和公开 Star 数量展示，不索取或保存 GitHub Token。

## 安装与升级

- 支持 Windows 10 / 11 x64。
- 安装包内置 Python 运行环境、ONNX 模型、FFmpeg 和 ffprobe，无需另外安装。
- 可以直接覆盖安装旧版本；升级会替换程序内部文件，但保留用户设置和外部输出目录。
- 当前安装包没有数字签名，Windows SmartScreen 可能显示未知发布者。请只从本 Release 下载并核对 SHA-256。
